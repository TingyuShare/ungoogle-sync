02

⚙️ Enable Developer Mode

1
Open the extensions page Type chrome://extensions in the Chrome address bar
2
Enable "Developer mode" Click the toggle in the top-right corner to turn it on
💡 Once enabled, you'll see more extension management options, including "Load unpacked"
3 / 8
03

📂 Load Extension

1
Drag the .crx file onto the page Drag the downloaded extension.crx onto the chrome://extensions page
2
Confirm installation Click "Add extension" in the popup dialog
✅
Installation complete The extension icon will appear on the right side of the Chrome toolbar
⚠️ If dragging doesn't work, try renaming the .crx to .zip, extracting it, and using the "Load unpacked" option instead
4 / 8
04

🔑 Enter Extension ID

1
Click the extension icon Click the Ungoogle Sync icon in the Chrome toolbar
2
Enter the extension ID Type the extension ID you copied from this page, e.g., nngceckbapebfimnlniiiahkandclblb
3
Save configuration Click Save, the extension will take effect automatically
5 / 8
05

🔄 Start Syncing

1
Click "Sync Now" The extension will encrypt and upload your data to your self-hosted server
2
Multi-device sync Install the same configuration on other devices, data will sync automatically
🔒 All data is encrypted during transmission and storage — only you can access it
